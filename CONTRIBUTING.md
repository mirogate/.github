# Contributing

Thanks for considering a contribution to a Mirogate open-source project.

## Before You Start

- Open an issue for bugs, behavior changes, or non-trivial improvements.
- Keep pull requests focused.
- Include a short explanation of the problem and the test or verification you ran.
- Do not include secrets, private keys, customer records, or production logs.

## Pull Request Checklist

- README instructions still work.
- Tests or validation commands pass.
- Security notes are updated if behavior changes.
- Changelog is updated for user-facing changes.

## Conduct

Be precise, respectful, and practical. Technical disagreement is fine; personal attacks are not.
